Endpoints are captured once as epoch milliseconds before validation, including for Date subtypes. The class stores no Date references and returns fresh base Date instances. Equal endpoints have zero duration. Extremely wide ranges remain valid, but durationMillis throws ArithmeticException if their mathematical duration exceeds Long.MAX_VALUE, rather than returning an overflowed negative duration. Subtype precision beyond milliseconds is outside this legacy API. Callers must not concurrently mutate inputs during construction.
