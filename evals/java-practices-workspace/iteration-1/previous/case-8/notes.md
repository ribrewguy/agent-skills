The compact constructor validates the code as exactly three ASCII uppercase letters and normalizes decimal scale with stripTrailingZeros. Record equality and hashing therefore agree for numerically equal amounts, including differently scaled zeros. Natural ordering compares currency first and numeric amount second, consistently with equality. plus rejects currency mismatches and uses BigDecimal.add without binary floating-point conversion or rounding. Negative amounts remain valid; currency codes are syntactically validated rather than checked against a changing registry.
