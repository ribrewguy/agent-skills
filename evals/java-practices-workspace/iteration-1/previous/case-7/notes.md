Composition owns the HashSet; AbstractSet provides ordinary Set equality, hashing and bulk operations. addAll funnels each element through add exactly once, avoiding inheritance double-counting. Removal (including iterator.remove), clear and duplicate insertion never reset or increment the lifetime counter; re-insertion increments it. Null elements follow HashSet behavior. On theoretical long counter exhaustion, new insertions throw before changing the set, while duplicates still return false. Like HashSet, this class is not thread-safe and expects stable element equality/hash codes while stored.
