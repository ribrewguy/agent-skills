The range captures each input's epoch milliseconds once and validates those retained values. It never invokes subtype-controlled clone() and returns fresh base Date objects. Null endpoints throw NullPointerException, reversed endpoints throw IllegalArgumentException, and equal endpoints are valid. Equality and hashing use both captured timestamps. durationMillis throws ArithmeticException when the mathematical nonnegative difference cannot fit in long. Construction requires stable inputs; capturing two independently mutable dates is not an atomic concurrent operation.
