The ledger remains intentionally mutable and single-threaded. It snapshots caller maps, validates the captured entries, and validates the entire request before deducting any count. All rejected argument requests leave counts unchanged; empty requests succeed. Returned maps are read-only snapshots, not backed views. Strings and Integers can safely be shared. Null arguments/entries throw NullPointerException; other invalid inputs throw IllegalArgumentException. Callers must keep inputs stable while copied. Fatal VM/resource failures are outside the argument-failure guarantee.
