Composition owns HashSet storage; AbstractSet is an intentional skeletal extension contract. Its inherited addAll calls add for each element, counting each successful insertion exactly once. Duplicate additions do not count, while remove/re-add counts again. Iterator removal, bulk removal, clear, Set equality/hashCode, and null support remain ordinary Set operations. Removal never resets the lifetime counter. This class is not thread-safe; the long counter has the normal finite long range and would overflow after Long.MAX_VALUE successful insertions.
