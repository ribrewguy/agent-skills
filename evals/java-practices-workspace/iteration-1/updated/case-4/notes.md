The snapshot owns immutable parcel values and a copied label. Each parcel getter is read once and the retained values are validated. Order, duplicates and empty lists survive. Accessors return a fresh array and an unmodifiable list containing fresh Parcel instances, so mutating a returned Parcel cannot change the shipment. Equality and hashing use parcel contents and label bytes. Nulls throw NullPointerException; blank IDs/SKUs and invalid quantities throw IllegalArgumentException. Inputs must not be modified concurrently during construction; this is not an atomic concurrent snapshot.
