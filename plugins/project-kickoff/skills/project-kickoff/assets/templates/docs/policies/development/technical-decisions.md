# Technical decision register

## Decision status

Use exactly `required`, `selected`, `proposed` or `unresolved` for a decision's status. Required records a binding capability or constraint; selected records an adopted implementation direction; proposed is a candidate without adoption; unresolved records a choice still to make. Separate capability mandates from implementation candidates. Rationale does not override status.
